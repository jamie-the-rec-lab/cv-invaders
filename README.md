# CV Invaders (moved)

CV Invaders now lives at **https://www.thereclab.ai/cv-invaders/**, with its
leaderboard on Vercel Blob. Its code is in the thereclab-site repo, under
`cv-invaders/`.

address there. The game files are kept for history only and are no longer
deployed; the Supabase project they used is being retired.
